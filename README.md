# Reinforced-Concrete Column Fire-Resistance Calculator

> **Backend:** C++17 · **Frontend / Web server:** Python 3 (Flask) · **UI:** HTML + Chart.js
> RU / EN / MN i18n

## ✨ Энэ хувилбарын онцлог

### Арматур — 3 бүлэг (группа), бодит байршлаар
Зургийн дагуу арматур **байрлалаараа биш, бүлгээрээ (группа)** ангилагдана:

| Бүлэг | Тайлбар | Халалт |
|---|---|---|
| **As₁** | Булангийн стержнүүд (4 булан) | Хоёр талаас халдаг → **хамгийн их** |
| **As₂** | Голын (дунд) стержнүүд (цөмд) | Нэг талаас → **хамгийн бага** |
| **As₃** | Нэмэлт стержнүүд (доод/дээд мөрд) | Нэг талаас, заавал биш (0 = унтраах) |

Бүлэг бүрт **диаметр Ø, тоо, галаас зай a**-г өөрөө оруулна. As талбай нь
`As = π·d²/4 · n` томьёогоор автоматаар тооцоологдоно. **γ (gamma steel)
бүлэг бүрт тусад нь** интерполяцаар бодогдоно — учир нь булан, гол, нэмэлт
стержнүүд галаас өөр зайд байгаа тул өөр өөрөөр халдаг.

### Бусад
- **φ** — λ-аас хамаарч **шугаман интерполяцаар автоматаар** (хоосон үлдээвэл).
  Хүсвэл гараар override хийж болно.
- **График 500 минут хүртэл**, 1-минутын нягтралтай.
- **Пф = яг хэдэн минут** — 1-минутын нарийвчлалаар тооцоолж, график дээр
  шар босоо шугам + "Пф = … мин" тэмдэглэгээгээр харуулна.
- Огтлолын зураг арматур бүрийг бүлгийн өнгөөр (булан=улаан, гол=цэнхэр,
  нэмэлт=ногоон) болон халалтаар нь өнгөөр ялгаж харуулна.

## 🚀 Quick start

```bash
cd backend && make && cd ..
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

http://localhost:5000 нээнэ үү.

## 🔌 API — `POST /api/calculate`

```json
{
  "b":300,"h":300,"H0":4000,"kL":0.8,
  "As1":3217,"a1":50,
  "As2":982,"a2":80,
  "As3":982,"a3":50,
  "Rbn":22,"Rsn":400,"rho":2300,"W":2,"tb":450,"t0":20,
  "Np":2354,"step":60,"tmax":500
}
```

Хариу: `phi` (авто эсвэл manual), `As1/As2/As3/AsTot`, бүлэг бүрийн
`ts1/ts2/ts3` ба `g1/g2/g3`, `chartRows` (1-мин), `tExact` (Пф), `verdict`.
